방향을 판단하는 조건문

PT의 예시처럼 반복해서 방향을 판단하고, 선택된 방향의 좌표를 10씩 바꿉니다. 무대 경계에서는 더 이동하지 않습니다.

만약 위로 기울이면 → Y +10
만약 아래로 기울이면 → Y −10
만약 왼쪽으로 기울이면 → X −10
만약 오른쪽으로 기울이면 → X +10

수업에서 이어 하기

  1. 교사와 원본 PT 7–9쪽을 보고 조건문을 예상합니다.
  2. 위두 조종기를 조립하고 실제 기울기 센서로 확인합니다.
  3. 스크래치에서 스프라이트·무대를 만들고 조건문을 코딩합니다.
  4. 가상 결과와 실제 움직임이 다르면 코드를 고칩니다.
